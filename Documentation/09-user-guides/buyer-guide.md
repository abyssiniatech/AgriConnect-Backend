# AgriConnect Ethiopia — Buyer Guide

## 1. Introduction

The AgriConnect Ethiopia platform enables buyers to discover agricultural products, communicate with sellers, place orders, and track purchases.

Buyers can use the platform to:

* Browse agricultural products.
* Search and filter products.
* View product details.
* Place orders.
* Track order status.
* Manage their profile.
* Receive notifications.
* Communicate with relevant platform participants where supported.

---

# 2. Getting Started

## 2.1 Create an Account

To create a buyer account:

1. Open the AgriConnect application.
2. Select **Register**.
3. Enter the required personal information.
4. Enter your email address and phone number.
5. Create a secure password.
6. Select **Buyer** as your role.
7. Submit the registration form.
8. Complete any required verification.

After registration, log in using your account credentials.

---

# 3. Logging In

1. Open the AgriConnect login page.
2. Enter your registered email or username.
3. Enter your password.
4. Select **Login**.

After successful authentication, the buyer dashboard is displayed.

If login fails, verify your credentials and try again.

---

# 4. Buyer Dashboard

The buyer dashboard provides access to the main buyer features.

Typical features include:

* Marketplace
* Products
* Orders
* Notifications
* Profile
* Account Settings

The dashboard may also display summaries such as recent orders and available products.

---

# 5. Browsing the Marketplace

The marketplace allows buyers to discover agricultural products offered by farmers and other approved sellers.

To browse products:

1. Open **Marketplace**.
2. Review available products.
3. Select a product to view its details.

Product information may include:

* Product name
* Description
* Category
* Price
* Available quantity
* Seller information
* Location
* Product image
* Availability status

---

# 6. Searching for Products

To search for a product:

1. Open the marketplace.
2. Enter the product name in the search field.
3. Submit the search.
4. Review the matching products.

Example searches:

```text
Maize
Wheat
Teff
Tomato
Potato
Coffee
```

If no matching products are found, the system should display an appropriate empty-state message.

---

# 7. Filtering Products

Buyers may filter products using available marketplace filters.

Possible filters include:

* Category
* Location
* Price range
* Availability
* Seller
* Product type

To apply a filter:

1. Open the marketplace.
2. Select the required filter.
3. Enter or select the desired value.
4. Apply the filter.

The marketplace should display products matching the selected criteria.

---

# 8. Viewing Product Details

To view detailed information:

1. Select a product from the marketplace.
2. Review the product information.
3. Check availability and price.
4. Review seller information.
5. Check the available quantity.
6. Select the appropriate purchase action.

Before placing an order, buyers should verify the product information carefully.

---

# 9. Placing an Order

To place an order:

1. Open the marketplace.
2. Select a product.
3. Open the product details.
4. Enter the required quantity.
5. Review the price.
6. Provide delivery information if required.
7. Review the order.
8. Select **Place Order**.
9. Confirm the order.

After successful submission, the system should create the order and display a confirmation.

---

# 10. Order Information

Buyers can view order information from the **Orders** section.

Information may include:

* Order number
* Product
* Quantity
* Price
* Seller
* Order date
* Delivery information
* Order status

---

# 11. Order Status

Depending on the implemented workflow, an order may have statuses such as:

* Pending
* Confirmed
* Processing
* Shipped
* Delivered
* Cancelled

Buyers should monitor order status for updates.

---

# 12. Cancelling an Order

If order cancellation is supported:

1. Open **Orders**.
2. Select the relevant order.
3. Review the order status.
4. Select **Cancel Order**.
5. Confirm the cancellation.

Cancellation may only be available for certain order statuses.

If cancellation is unavailable, the buyer should contact the seller or platform support where appropriate.

---

# 13. Delivery Tracking

Buyers can review delivery information associated with their orders.

Information may include:

* Delivery status
* Pickup location
* Destination
* Logistics provider
* Estimated delivery information
* Delivery updates

The exact tracking features depend on the implemented logistics integration.

---

# 14. Notifications

Buyers may receive notifications for:

* Order confirmation.
* Order status changes.
* Delivery updates.
* Product-related updates.
* Platform announcements.
* Other relevant activities.

To view notifications:

1. Select the notification icon.
2. Open the notification list.
3. Select a notification.
4. Review the information.
5. Mark it as read if supported.

---

# 15. Profile Management

Buyers should keep their profile information accurate.

Possible profile information includes:

* Full name
* Email
* Phone number
* Location
* Profile image
* Delivery information

To update your profile:

1. Open **Profile**.
2. Select **Edit Profile**.
3. Update the required information.
4. Save the changes.

---

# 16. Account Security

Buyers should:

* Use a strong password.
* Never share their password.
* Log out on shared devices.
* Avoid suspicious links.
* Keep account information updated.
* Protect authentication information.
* Report suspicious account activity.

---

# 17. Troubleshooting

## Cannot Log In

Check:

* Email or username.
* Password.
* Internet connection.
* Account status.

If the problem continues, use the available account recovery process or contact support.

---

## Product Cannot Be Found

Check:

* Search spelling.
* Product filters.
* Category selection.
* Location filter.
* Product availability.

Remove unnecessary filters and search again.

---

## Cannot Place an Order

Check:

* Product availability.
* Requested quantity.
* Required order information.
* Delivery information.
* Internet connection.

If the problem continues, review the displayed error message and contact support if necessary.

---

## Order Is Not Displayed

Refresh the order page and verify that the order was successfully submitted.

If the order is still missing, keep the order confirmation information and contact support.

---

## Delivery Information Is Missing

Check the order status and notification area.

If delivery information is still unavailable, contact the seller or logistics support where appropriate.

---

# 18. Good Practices for Buyers

Buyers should:

* Review product details before ordering.
* Confirm quantities carefully.
* Verify prices before submitting an order.
* Provide accurate delivery information.
* Monitor order status.
* Check notifications regularly.
* Keep account information secure.
* Report suspicious activity.
* Contact support when problems cannot be resolved.

---

# 19. Support

When reporting a problem, provide:

* Buyer account information that is safe to share.
* Order number.
* Product ID or product name.
* Description of the issue.
* Date and time of the problem.
* Error message.
* Screenshot when available.

Do not send passwords, authentication tokens, or other sensitive credentials to support personnel.

---

# 20. Summary

The AgriConnect buyer interface provides tools for discovering agricultural products, comparing available listings, placing orders, tracking purchases, receiving notifications, and managing account information.

Buyers should carefully review product and order information and maintain secure account practices when using the platform.
